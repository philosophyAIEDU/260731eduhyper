# 디자인 시스템

Claude Code 가 화면을 만들 때 따르는 기준입니다.
채널 톤을 바꾸고 싶으면 이 파일만 고치면 됩니다.

## 컬러

| 역할 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 배경 | `#0B1026` | 전 씬 공통. 절대 바꾸지 않는다. |
| 강조 (시안) | `#4CE0D2` | 핵심 개념, 온스크린 대사, 결론 |
| 사건색 A (골드) | `#D4AF37` | 한 씬에서만 쓰는 특별한 오브젝트 |
| 사건색 B (마젠타) | `#FF4FD8` | 변화·전파를 보여줄 때만 |
| 글자 | `#EAF0FF` | 본문 (순백 아님 — 배경 색조로 살짝 틴트) |
| 보조 글자 | `#8FA0C4` | 라벨, 설명, 부제 |

**규칙:** 강조색은 시안 하나. 골드·마젠타는 "그 씬에서만 일어나는 사건"을 표시하는
색이라 남발하면 의미가 사라집니다.

## 글꼴 — Pretendard

| 용도 | weight | 크기 기준 (1920×1080) |
| --- | --- | --- |
| 온스크린 대제목 | 900 | 90–160px |
| 소제목 / 강조 | 700 | 44–92px |
| 본문 | 400 | 30–44px |
| 보조 설명 | 300 | 28–40px |

- 어두운 배경에서는 글자가 더 굵어 보입니다. 본문은 400 대신 **300**을 쓰면 편합니다.
- 큰 글자에는 `letter-spacing: -0.03em` 을 줍니다.
- 숫자·영문 코드(BIT, QUBIT, 0/1 같은 것)는 **JetBrains Mono** 를 쓰면
  "기계의 언어" 라는 느낌이 살아납니다. 이 폰트는 HyperFrames 에 내장돼 있어
  따로 설치할 필요가 없습니다.

## 배경

`index.html` 에 이미 만들어져 있습니다. **씬에서 배경을 다시 그리지 마세요.**

- 짙은 네이비 바탕
- 은은한 별빛 44개 (시드 고정 — 렌더할 때마다 같은 자리)
- 좌상단·우하단 라디얼 글로우 (천천히 호흡)
- 가장자리 비네팅
- 마지막 2초 암전

씬은 **오브젝트만** 담습니다. 그래야 씬이 바뀌어도 배경이 튀지 않습니다.

## 움직임

- 등장은 **0.4~0.8초**, `power3.out` 또는 `back.out(1.5)` 기본
- 씬 하나에 유휴 모션(호흡·드리프트)은 **하나만**. 여기저기 흔들리면 산만합니다.
- **그림이 먼저, 이름이 나중.** 개념이 시각적으로 완성된 다음에
  온스크린 텍스트를 띄웁니다. 설명 영상의 기본 문법입니다.
- 화면이 잠깐 멈추는 건 괜찮습니다. 오히려 중요한 문장 직전의 정적은
  다음 것을 돋보이게 합니다.

## 하지 말 것

- 그라디언트 글자 (`background-clip: text`)
- 똑같은 카드 여러 장 나열
- 글로우 남발 — 발광은 "지금 뭔가 일어나고 있다" 는 뜻일 때만
- 순수 `#000` / `#fff`
- 한 화면에 요소 4개 이상 — 설명 영상은 한 번에 하나씩
