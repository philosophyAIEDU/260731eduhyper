PART 3. HyperFrames 제작 프롬프트

주제 : Claude Code + HyperFrames 로 모션그래픽 영상 만들기

※ 아래 초 단위는 기획 단계 예상치입니다.
   실제 낭독 전사 결과에 맞춰 전 구간을 재배치하세요.
   여기 적힌 초는 씬 순서와 비율 참고용입니다.


/hyperframes 로 1920x1080, 30fps 컴포지션을 만들어줘.
전체 길이는 내레이션 오디오 길이에 맞춰줘.


[씬 0] 인사 (대략 0~5초)
- 요소: 채널 워드마크 "필로소피 AI 교육"
- 애니메이션: 중앙에 조용히 페이드인 → 페이드아웃. 배경만 남는다.
- 텍스트: (없음 — 인사말 구간을 덮는 용도)


[씬 1] 훅 (대략 5~20초)
- 요소: 좌측에 애프터이펙트를 뜻하는 사각 아이콘(보조색 #8FA0C4),
        우측에 마이크 아이콘(시안 #4CE0D2)
- 애니메이션:
    · AE 아이콘이 먼저 등장
    · "이제는 아닙니다" 발화 시점에 AE 아이콘 위로 X 슬램(스케일 1.6→1.0),
      아이콘이 어둡게 가라앉음
    · 이어서 마이크 아이콘이 back.out 으로 팝인하며 밝아짐
- 텍스트: "이제는 아닙니다"


[씬 2] 원리 — 프레임 (대략 20~50초)
- 요소: 웹페이지를 뜻하는 카드 1장 → 우측으로 이어지는 필름 스트립 5칸
- 애니메이션:
    · 카드가 등장 후, "한 프레임씩" 발화에 맞춰 스트립 칸들이 순차 복제되며 펼쳐짐
    · 각 칸 아래 시각 라벨 0.00s / 0.03s / 0.07s … (JetBrains Mono)
    · "1초에 30장" 발화에 맞춰 우측에 카운터 "30장 = 1초" 등장
- 텍스트: "웹페이지 = 영상"


[씬 3] 원리 — 타이밍 (대략 50~80초)
- 요소: 상단 음성 파형 바, 중단 단어 3~4개(각각 시각 라벨), 하단 코드 한 줄
- 애니메이션:
    · 파형 위를 재생 헤드(시안 세로선)가 좌→우로 지나감
    · 헤드가 각 단어를 지날 때 그 단어와 시각이 확정되듯 밝아짐
    · "10.72초" 가 확정되는 순간, 그 숫자가 아래 코드 줄로 이동하듯 복사됨
      코드: tl.to("#x-mark", { scale: 1 }, 10.72);
- 텍스트: "말 → 초 → 코드"


[씬 4] 사용자가 하는 일 (대략 80~110초)
- 요소: 번호 카드 4장 — ① 기획서 3장 ② 낭독 녹화 ③ 프롬프트 붙여넣기 ④ 타이밍 확인
- 애니메이션:
    · 발화에 맞춰 한 장씩 순차 등장 (stagger 총 0.5초 이내)
    · "그게 전부입니다" 에서 ③④ 만 시안으로 남고 ①② 는 어둡게 가라앉음
- 텍스트: "당신이 하는 건 4단계"


[씬 5] 경고 — 한글 경로 (대략 110~130초)
- 요소: 경로 문자열 2줄 (모노)
    ❌ C:\Users\...\바탕화면\내영상\
    ✅ C:\Users\...\hyper\my-video\
- 애니메이션:
    · 한글 경로 줄 등장 → 짧은 좌우 흔들림 + X 표시, 회색으로 가라앉음
    · 영어 경로 줄이 시안 체크와 함께 안정적으로 등장
    · 흔들림은 0.3초 이내로 짧게. 머뭇거리지 않는다.
- 텍스트: "경로에 한글 금지"


[씬 6] 마무리 (대략 130~150초)
- 요소: 저장소 주소 + 채널 워드마크
- 애니메이션:
    · 주소가 한 글자씩 타이핑되듯 등장 (discrete, 커서 깜빡임 없음)
    · 뒤에서 라디얼 글로우가 부드럽게 피어오름
    · 배경 서서히 어두워지며 마무리
- 텍스트: "github.com/philosophyAIEDU/260731eduhyper"

· 유휴 모션은 씬당 하나. 배경 호흡은 루트가 이미 담당한다.
· 온스크린 텍스트는 해당 개념이 화면에서 완성된 직후에 등장.
