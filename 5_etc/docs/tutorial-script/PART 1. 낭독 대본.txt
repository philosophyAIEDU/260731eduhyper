PART 1. 낭독 대본 (촬영용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━
주제 : Claude Code + HyperFrames 로 모션그래픽 영상 만들기
예상 : 약 2분 30초
※ 아래 타임코드는 예상치입니다. 실제 녹음 길이에 맞춰 나중에 재배치됩니다.


【인사 · 0:00~0:05】
안녕하세요, 필로소피입니다.


【훅 · 0:05~0:20】
"모션그래픽 영상을 만들려면 애프터이펙트를 배워야 한다"
이런 이야기, 들어보셨습니까? //
이제는 아닙니다.
목소리만 녹음하면, 나머지는 AI가 만들어 줍니다.


【본론 1 — 원리 · 0:20~0:50】
먼저 원리부터 말씀드리겠습니다.
하이퍼프레임은 영상을 그리지 않습니다. //
웹페이지를 한 프레임씩 스크린샷으로 찍습니다.
영상은 결국 1초에 30장의 정지 이미지니까요.
그래서 "몇 초에 무엇이 어떻게 움직인다"를 코드로 적어 두면,
그 코드가 곧 영상이 됩니다. //
그리고 코드를 쓰는 일은, 클로드가 아주 잘하는 일입니다.
모션그래픽이 디자인 작업에서 코딩 작업으로 바뀐 겁니다.


【본론 2 — 목소리에 맞추는 법 · 0:50~1:20】
그런데 여기서 진짜 중요한 게 하나 있습니다.
화면을 목소리에 어떻게 맞추느냐입니다. //
음성 인식으로 녹음을 전사하면,
어떤 단어가 몇 초에 나오는지 표가 만들어집니다.
"사실이 아닙니다" 라고 말하는 순간이 10.72초다,
이렇게 정확한 숫자가 나옵니다. //
그러면 클로드는 10.72초에 엑스 표시를 띄우는 코드를 씁니다.
눈대중이 아니라 계산으로 맞추는 겁니다.


【본론 3 — 실제로 하는 일 · 1:20~1:50】
그럼 여러분이 실제로 하실 일은 무엇이냐. //
첫째, 기획서 세 장을 씁니다.
대본, 씬별 지시서, 제작 사양. 양식은 준비돼 있습니다. //
둘째, 오비에스로 대본을 읽어서 녹화합니다.
화면은 쓰지 않습니다. 목소리만 씁니다. //
셋째, 클로드 코드에 프롬프트를 붙여 넣습니다.
넷째, 클로드가 보여주는 타이밍을 한 번 확인해 줍니다. //
그게 전부입니다. 나머지는 클로드가 합니다.


【본론 4 — 함정 하나 · 1:50~2:10】
마지막으로 꼭 아셔야 할 게 하나 있습니다. //
작업 폴더 경로에 한글이 있으면 안 됩니다.
하이퍼프레임은 한글 경로에서 에러 메시지 없이 조용히 멈춰버립니다. //
저도 이것 때문에 한 시간 반을 썼습니다.
바탕화면에 한글 폴더를 만들고 시작하면 바로 막힙니다.
준비된 프롬프트에 이 내용이 들어 있으니, 그대로 쓰시면 됩니다.


【정리 · 2:10~2:30】
정리하겠습니다.
목소리를 녹음하고, 기획서를 쓰고, 프롬프트를 붙여 넣는다. //
깃허브에 전부 올려두었습니다.
주소는 화면과 설명란에 있습니다.
직접 한번 만들어 보시죠.
