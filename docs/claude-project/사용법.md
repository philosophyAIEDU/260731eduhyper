# 기획서 3장, Claude 프로젝트로 쓰기

이 폴더의 [`지침.md`](지침.md) 는 **Claude 프로젝트**(claude.ai 의 "Projects" 기능)에
붙여넣어 두면, 주제 하나만 던져도 PART 1~3(대학 강의용은 PART 4까지) 기획서를
알아서 써 주는 지침입니다. Sam(설계) · Jenny(대본) · Will(시각화) 세 역할이
순서대로 작업하는 방식으로 짜여 있습니다.

`templates/` 의 빈 양식을 직접 채우기 막막하다면, 이 방법이 훨씬 빠릅니다.

---

## 1. Claude 프로젝트 만들기 (처음 한 번만)

1. https://claude.ai 접속 후 로그인
2. 왼쪽 사이드바에서 **"프로젝트"** 클릭 → **"프로젝트 만들기"**
3. 이름을 정합니다. 예: `학습 영상 대본 작성팀`
4. 설명(선택): `학습 영상 대본 작성을 도와줍니다`
5. 만들어진 프로젝트에서 우측 **"지침"** 칸의 연필(✏) 아이콘 클릭
6. 이 저장소의 [`지침.md`](지침.md) 내용을 **처음부터 끝까지 전체 복사**해서
   그대로 붙여넣고 저장

한 번만 해 두면 됩니다. 이후로는 이 프로젝트에서 새 채팅을 열 때마다
같은 팀이 작업합니다.

---

## 2. 기획서 만들기

프로젝트 안에서 새 채팅을 열고, 주제만 말하면 됩니다.

```
양자컴퓨터의 원리와 양자컴퓨터가 할 수 있는 일에 관한 영상의 대본이 필요합니다
```

Sam 이 먼저 몇 가지를 확인합니다 (대상, 길이, 활용 방식 등).
**"알아서 해줘"** 라고 해도 되고, 하나씩 답해도 됩니다.

```
질문: 이 영상의 주 시청 대상은 누구인가요?
답변: 직장인 등 일반 성인 교양

질문: 영상 길이는 어느 정도로 생각하시나요?
답변: 3분 내외

질문: 이 영상은 어떻게 쓰일 예정인가요?
답변: 유튜브 등 공개 콘텐츠
```

확인이 끝나면 Sam → Jenny → Will 순서로 작업해서
**PART 1(대본) · PART 2(씬별 지시서) · PART 3(제작 프롬프트)** 를 한 번에 내놓습니다.
대학 강의를 위한 자료라면 자동으로 **대학 강의 모드**가 되어 **PART 4(수업 연계 자료)** 까지 나옵니다.

---

## 3. 결과물을 파일로 저장하기 — 이름이 중요합니다

Claude 가 만든 결과에서 **PART 1 / 2 / 3 블록만 각각 복사**해서,
아래 이름 그대로 저장하세요. 이 저장소의 프롬프트(`templates/Claude Code 에 붙여넣을 프롬프트.txt`)가
이 파일명을 그대로 찾습니다.

```
C:\Users\사용자명\hyper\source\
    PART 0. 녹화본.mkv              ← OBS 로 PART 1을 읽어서 녹화한 것
    PART 1. 낭독 대본.txt           ← Claude 프로젝트의 "PART 1" 블록
    PART 2. 씬별 지시서.txt         ← "PART 2" 블록
    PART 3. 제작 프롬프트.txt       ← "PART 3" 블록
```

> 💡 Claude 프로젝트의 출력은 `📹 [영상 제목]`, `👥 팀 기여 요약`, `📊 후반 작업 가이드`
> 같은 관리용 섹션도 함께 나옵니다. 이건 저장하지 않아도 됩니다 — HyperFrames 로
> 넘어가는 데 필요한 건 PART 1·2·3 세 블록뿐입니다.

**대학 강의 모드로 PART 4가 나왔다면**, 그건 별도로 `PART 4. 수업 연계 자료.txt`
같은 이름으로 보관하세요. 확인문제·LMS 설명문 등은 **영상 제작(HyperFrames)에는
쓰이지 않고, 강의 운영에 따로 쓰는 자료**입니다.

## 4. 색상 팔레트에 대해

PART 3 끝의 컬러 팔레트가 `#______` 로 비어 있는 채로 나올 수 있습니다.
채우지 않아도 됩니다 — 비어 있으면 Claude Code 가 이 저장소의
[`frame.md`](../../frame.md) 기본 팔레트(네이비 배경 + 시안 강조)를 씁니다.

특정 영상만 다른 색을 쓰고 싶으면 이 칸을 채우거나, Claude Code 에게
"이번 영상은 붉은 계열로 해줘" 라고 말로 지시해도 됩니다.

## 5. 그다음은 평소와 같습니다

PART 1·2·3 를 저장했다면, 이제부터는 [메인 README](../../README.md) 의
④번 단계부터 그대로 따라가면 됩니다 — `templates/Claude Code 에 붙여넣을
프롬프트.txt` 를 Claude Code 에 붙여 넣으면 됩니다.

```
①  Claude 프로젝트로 기획서 3장 쓰기     ← 이 문서
       ↓
②  OBS 로 PART 1 낭독 녹화
       ↓
③  녹화본 + PART 1·2·3 를 hyper\source 폴더에 모으기
       ↓
④  Claude Code 에 프롬프트 붙여넣기      ← 메인 README 참고
       ↓
⑤  타이밍 확인
       ↓
⑥  완성
```

## 자주 있는 질문

**Q. 대학 강의 모드는 어떻게 켜나요?**
따로 켤 필요 없습니다. Sam 이 인터뷰에서 "대학" 또는 "수강생" 이라고
답하면 자동으로 그 모드로 진행됩니다.

**Q. 결과가 마음에 안 들면?**
같은 채팅에서 바로 "PART 1을 조금 더 쉬운 말로 다시 써줘" 처럼
말하면 됩니다. 프로젝트 안에서는 대화가 이어지니 새로 시작할 필요 없습니다.

**Q. 이 지침을 우리 채널에 맞게 고쳐도 되나요?**
네. `지침.md` 는 그대로 텍스트 문서입니다. 톤이나 체크리스트를
채널 사정에 맞게 고친 뒤, 프로젝트의 "지침" 칸에 다시 붙여넣으면 됩니다.
