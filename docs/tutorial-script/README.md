# 강의 영상 대본 — Claude Code + HyperFrames

이 폴더는 **이 키트를 소개하는 영상**의 기획서 3장입니다.
동시에 **기획서를 어떻게 쓰는지 보여주는 실제 예시**이기도 합니다.

`templates/` 의 빈 양식이 막막하면 여기를 먼저 보세요.

| 파일 | 내용 |
| --- | --- |
| `PART 1. 낭독 대본.txt` | OBS 앞에서 그대로 읽을 문장 (약 2분 30초) |
| `PART 2. 씬별 지시서.txt` | 7개 씬에 무엇이 나오는지 |
| `PART 3. 제작 프롬프트.txt` | 색·움직임 세부 사양 |

## 이 대본으로 영상 만들기

1. `PART 1` 을 OBS 로 읽어서 녹화합니다
2. 녹화본과 이 세 파일을 한 폴더에 모읍니다
3. `templates/Claude Code 에 붙여넣을 프롬프트.txt` 를 Claude Code 에 붙여 넣습니다

## 대본을 쓸 때 참고할 점

- **한 문장 = 한 줄.** 문장이 곧 화면 전환의 단위가 됩니다.
- **`//` 는 쉬어 가는 곳.** 화면이 바뀔 여유를 만듭니다.
- **인사말도 대본에 적으세요.** "안녕하세요, ○○입니다" 를 빼먹으면
  그 구간에 화면이 비어 버립니다. `PART 1` 의 【인사】 구간이 그래서 있습니다.
- **타임코드는 예상치입니다.** 실제 낭독은 거의 항상 더 깁니다.
  (실측: 60초로 기획한 대본이 실제로는 83.5초)
  Claude 가 전사 결과를 보고 전부 다시 배치합니다.
- **씬은 4~7개.** 너무 잘게 쪼개면 산만합니다.
- **한 씬에 개념 하나, 요소는 3개 이하.**
